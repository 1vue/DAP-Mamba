# Data Preparation

Create a new directory named `dataset` outside the repository to store all datasets. The default scripts use paths relative to the repository root, such as `../../dataset`.

## Ref-Youtube-VOS

Download the Ref-Youtube-VOS dataset from the challenge website [here](https://competitions.codalab.org/competitions/29139#participate-get_data). Then extract and organize the files as follows:

```text
DAP-Mamba
├── dataset
│   ├── ref-youtube
│   │   ├── meta_expressions
│   │   │   ├── train
│   │   │   │   ├── meta_expressions.json
│   │   │   ├── valid
│   │   │   │   ├── meta_expressions.json
│   │   ├── train
│   │   │   ├── JPEGImages
│   │   │   ├── Annotations
│   │   ├── valid
│   │   │   ├── JPEGImages
│   │   │   ├── Annotations
```

## Ref-DAVIS17

Download the DAVIS2017 files from the official website [here](https://davischallenge.org/davis2017/code.html). You only need `DAVIS-2017-Unsupervised-trainval-480p.zip` and `DAVIS-2017_semantics-480p.zip`.

Download the referring expression annotations from the project page [here](https://www.mpi-inf.mpg.de/departments/computer-vision-and-machine-learning/research/video-segmentation/video-object-segmentation-with-language-referring-expressions). Then put the zip files in the following directory:

```text
DAP-Mamba
├── dataset
│   ├── davis
│   │   ├── DAVIS-2017_semantics-480p.zip
│   │   ├── DAVIS-2017-Unsupervised-trainval-480p.zip
│   │   ├── davis_text_annotations.zip
```

Unzip these files:

```bash
unzip -o davis_text_annotations.zip
unzip -o DAVIS-2017_semantics-480p.zip
unzip -o DAVIS-2017-Unsupervised-trainval-480p.zip
```

Preprocess the dataset to Ref-Youtube-VOS format. (Make sure you are in the main directory)

```
python tools/convert_davis_to_ytvos.py
```

Finally, unzip the file `DAVIS-2017-Unsupervised-trainval-480p.zip` again (since we use `mv` in preprocess for efficiency).

```
unzip -o DAVIS-2017-Unsupervised-trainval-480p.zip
```

## A2D-Sentences

Download and extract the A2D-Sentences dataset from the project website [here](https://kgavrilyuk.github.io/publication/actor_action/). We use the COCO-format annotation files generated by MTTR, which can be downloaded from Google Drive [here](https://drive.google.com/drive/u/0/folders/1daTuACcZUKuzgl0iqzwCfKm_tSISarFl).

The expected directory structure is:

```text
DAP-Mamba
├── dataset
│   ├── a2d_sentences
│   │   ├── Release
│   │   ├── text_annotations
│   │   │   ├── a2d_annotation_with_instances
│   │   │   ├── a2d_annotation.txt
│   │   │   ├── a2d_missed_videos.txt
│   │   ├── a2d_sentences_single_frame_test_annotations.json
│   │   ├── a2d_sentences_single_frame_train_annotations.json
│   │   ├── a2d_sentences_test_annotations_in_coco_format.json
```

If the COCO-format annotation file is not available, use the helper scripts in `tools/a2d_sentences/` to convert the annotations.
